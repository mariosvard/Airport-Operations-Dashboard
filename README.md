# Airport-Operations-Dashboard

## Overview

Airport Operations Dashboard is a web application management system that uses PHP as the programming language.
The project was developed in order to create an advanced simulation system for airport operations interface that involves the control of airport operations, operational status, and dashboard using an interactive web application.

This dashboard has been implemented as a full stack PHP application that can be hosted through Docker and Render.

---

# Project Goals

The key goals for the project were as follows:

- Develop an adaptive airport operations dashboard.
- Develop an intuitive user interface design.
- Acquire skills in backend programming with PHP.
- Merge the frontend and backend elements.
- Deploy a functional PHP application online-Learn about containerization using Docker and GitHub.
